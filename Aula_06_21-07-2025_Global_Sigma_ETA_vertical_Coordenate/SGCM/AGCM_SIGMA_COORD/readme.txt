Simplified Hemispheric/Global Circulation Model

by kubota January 30, 2006

========================================

TOPO.dat    : Surface topography (currently not used)
T0.dat      : Input data of temperature (climatology for July 20 -
              August 18, 1979-1995)
U0.dat      : Input data of zonal wind
V0.dat      : Input data of meridional wind
P0.dat      : Input data of surface pressure
input.ctl   : A control file for input data file
outputg.ctl : A control file for output data file of global version
